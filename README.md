# Prarthana Gopinath — Portfolio Website

A responsive dark portfolio website for a Python Developer and Data Analyst. Built with HTML, CSS, and vanilla JavaScript. No framework or build tools required.

## Run locally
1. Extract the ZIP.
2. Open the `Prarthana_Portfolio` folder.
3. Double-click `index.html`, or open it with VS Code and use Live Server.

## Personalize before publishing
- **Profile photo:** Add your portrait to `assets/` and name it `profile.jpg`. A placeholder with initials appears until you add it.
- **Email:** In `index.html`, replace `your.email@example.com` in the `mailto:` link with your real email.
- **LinkedIn:** Add your LinkedIn profile URL to the social links/contact section if desired.
- **Education:** Replace the sample education sentence with your exact degree, institution, and graduation year.
- **Projects:** Add repository/demo URLs where the project cards currently say “Add your … link”. Only add links to projects that are complete and publicly accessible.
- **Resume:** To add a resume button, place your PDF in the project folder and add a link to it in the hero or contact section.

## Publish free with GitHub Pages
1. Create a GitHub repository, for example `my-portfolio`.
2. Upload all files and folders from this project (keep `index.html` at the repository root).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for the published URL shown in the Pages section.

## Included features
- Responsive desktop and mobile layout
- Dark visual theme with gradient accents
- Mobile navigation
- Animated section reveals
- Filterable project cards
- Project links for the known CivicPulse and Customer Churn repositories
- Profile photo fallback until a real photo is added
